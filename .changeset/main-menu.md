- The game opens on a main menu with Start and Options.
- Start lets the player pick a game mode and play a random or seeded run.
- There are 5 game modes: Standard, Hardcore, Chaos, Beastmaster and Gambler.
- Options can turn off shaking, projectiles and the battle countdown.
- The run over screen shows the seed, and can retry it or go back to the menu.
